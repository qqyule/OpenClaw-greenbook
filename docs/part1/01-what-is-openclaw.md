# 01 OpenClaw 是什么？

欢迎来到 OpenClaw 的世界！如果你是第一次听说这个名字，或者被它的“龙虾”吉祥物吸引过来，那么你找对地方了。

### 一句话理解 OpenClaw
OpenClaw 不仅仅是一个聊天机器人（像 ChatGPT 那样），它是一个**开源、自托管的 AI 智能体（Agent）系统**。

如果把 ChatGPT 比作一个博学多才的“顾问”，你问它答；那么 OpenClaw 就是一个**“数字员工”**。它不仅能动口，还能动手帮你干活。

### 为什么说它是“数字员工”？
*   **主动执行**：它能主动管理你的日程、处理邮件、操作浏览器，甚至帮你写代码。
*   **全渠道接通**：你可以通过飞书、钉钉、微信、Telegram 等你常用的聊天软件跟它说话，它就在那里 24 小时待命。
*   **隐私安全**：它是“自托管”的，意味着你可以把它安装在你自己的电脑或服务器上，数据完全由你掌控。

### OpenClaw vs. ChatGPT：有什么不同？

| 维度 | ChatGPT | OpenClaw |
| :--- | :--- | :--- |
| **角色** | 问答顾问 | 数字员工（智能体） |
| **工作方式** | 你问它答 | 接收任务，自主寻找工具执行 |
| **地盘** | 网页/App | 你的服务器，接入 20+ 聊天平台 |
| **大脑选择** | 只能用 GPT 系列 | 可以选 Claude, GPT, DeepSeek 甚至本地模型 |
| **所有权** | 数据在 OpenAI 手里 | 数据在你手里，完全开源 |

### 独特的“养虾”文化
在 OpenClaw 社区，我们把运行和调教 OpenClaw 称为**“养虾”**（因为吉祥物是龙虾）。如果你正在阅读这份文档，恭喜你，你即将成为一名光荣的“养虾人”！
