# 02 发展简史：GitHub 上的奇迹

OpenClaw 的崛起速度在整个开源历史上都是罕见的。它从一个人的“周末小项目”，变成了全球最火的 AI 智能体平台。

### 时间轴：从 0 到 27 万 Star

*   **2025年11月：诞生**
    奥地利开发者 Peter Steinberger 闲着没事，写了一个能连聊天软件的 AI 小工具，取名 `ClawdBot`（致敬 Claude），龙虾吉祥物就此诞生。
*   **2026年1月中旬：大爆发**
    短短 72 小时内，项目获得了 6 万个 GitHub Star！全世界的开发者都疯了，平均每 10 秒就有人点赞。
*   **2026年1月27日：被迫改名**
    因为名字太像 `Claude`，收到了商标警告。临时改名 `Moltbot`（意为龙虾蜕壳）。
*   **2026年1月30日：定名 OpenClaw**
    为了强调开源属性，正式更名为 `OpenClaw`。
*   **2026年2月：成长与风波**
    经历了安全漏洞修复和创始人加入 OpenAI 的大新闻。项目移交给开源基金会，保持独立运营。
*   **2026年3月3日：登顶全球第一**
    GitHub Star 数超越了著名的前端框架 `React`，正式成为全球最受关注的开源软件项目。

### 为什么速度这么快？
作为对比，React 达到 23 万 Star 用了超过 10 年，而 OpenClaw 只用了不到 5 个月。这说明了全世界对于“拥有一个属于自己的 AI 员工”的需求是多么巨大。
