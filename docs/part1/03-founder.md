# 03 创始人故事：一位“建造者”的纯粹

OpenClaw 的灵魂人物是 **Peter Steinberger**。

### 从周末项目开始
Peter 是一位在 iOS 开发圈非常有名的奥地利开发者。他开发 OpenClaw 的初衷非常简单：想要一个能随时随地通过手机消息帮他处理杂事的 AI。

他曾说：“我骨子里就是一个建造者（Builder）。我想改变世界，而不是建一家大公司。”

### 加入 OpenAI 的波折
2026 年 2 月，当 OpenClaw 火遍全球时，Sam Altman（OpenAI CEO）邀请 Peter 加入 OpenAI。

当时社区非常担心：OpenClaw 会不会变成 OpenAI 的私有工具？
Peter 表现得非常坦诚，他做出了三个承诺：
1.  OpenClaw 移交给独立基金会，保持完全开源。
2.  OpenAI 只是赞助商，不控制项目方向。
3.  他会继续投入 OpenClaw 的开发。

### 名字背后的趣味
最初的名字 `ClawdBot` 来源于对 Anthropic `Claude` 模型的喜爱。虽然因为版权被迫改名两次，但“龙虾”这个形象却深深植入了社区。

如今，这只龙虾已经成为了“开源 AI 智能体”的图腾。
