# 04 为什么这么火？社交、金钱与未来

如果你问最近 AI 圈什么最火，十个人里有九个会提到“养虾”。

### 1. 它是真正的“社交货币”
因为吉祥物龙虾太可爱，加上“养虾人”这个称呼非常有意思，OpenClaw 迅速在社交平台出圈。在深圳，甚至出现了地方政府专门出台政策支持 OpenClaw 发展的现象。

### 2. 它能帮你赚钱
这不是开玩笑。在 OpenClaw 的生态里，有很多“赚钱型”玩法：
*   **自动交易**：利用 AI 在预测市场（如 Polymarket）进行自动博弈。
*   **数字员工**：帮人处理繁琐的表格、数据抽取任务，有人靠它在 11 小时内赚到了 1.5 万美元。

### 3. Moltbook：Agent 的社交网络
OpenClaw 甚至催生了一个叫 `Moltbook` 的平台，那是专门给 AI Agent 社交的地方。几万个 Agent 在上面发帖、回帖、讨论哲学。这让我们第一次看到：AI 不仅仅是工具，它们正在形成自己的“社会”。

### 4. 强大的 Skills（技能）生态
在 `ClawHub` 技能市场上，已经有超过 13,000 个现成的技能。你想让它刷网页、发推特、定外卖？只要装个 Skill 就能搞定。

### 避坑指南：火热背后的冷思考
虽然好玩，但新手也要注意：
*   **API 账单**：如果配置不当，AI 可能会在后台跑出巨额账单。
*   **安全风险**：不要随便安装不明来源的 Skill，防止数据泄露。

准备好了吗？下一章我们将深入 OpenClaw 的内部，看看这个“数字员工”的大脑是如何运作的。
