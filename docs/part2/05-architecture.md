# 05 整体架构：大脑、躯干与神经

为了让小白也能听懂，我们可以把 OpenClaw 的架构比作一个**人的身体**。

### 1. Gateway（大脑）：中央控制中心
这是 OpenClaw 的“核心大脑”。它负责思考、下达指令、记住你是谁。
*   它不休息，24 小时在线。
*   所有的决策都在这里发生。

### 2. Node（躯干/手脚）：执行节点
这是负责干活的部分。比如：
*   控制摄像头拍张照。
*   在你的屏幕上点一下。
*   在电脑里运行一段代码。
*   **注意**：大脑可以装在云端服务器上，而手脚（Node）可以装在你身边的电脑上，它们通过网络连接。

### 3. Channel（神经）：沟通渠道
这是 AI 跟外界说话的通道。
*   比如飞书、钉钉、Telegram。
*   通过这些“神经”，你可以随时随地给“大脑”发消息。

### 总结：它是如何工作的？
1.  你通过 **Channel**（比如飞书）发了一个指令：“帮我查一下明天的天气”。
2.  **Gateway**（大脑）接收到指令，开始思考，并决定去调用“天气查询”技能。
3.  **Node**（手脚）去网页上抓取数据。
4.  **Gateway** 整理好结果，通过 **Channel** 回复给你。

这种分工明确的架构，让 OpenClaw 既强大又灵活。
