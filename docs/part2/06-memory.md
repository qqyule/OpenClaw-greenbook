# 06 记忆系统：它为什么记得你？

普通聊天机器人可能聊完就忘，但 OpenClaw 拥有像人类一样的“长短期记忆”。

### 四层记忆模型：从“灵魂”到“聊天记录”

1.  **SOUL（灵魂内核）**
    这是它的“出厂设置”。定义了它叫什么名字、性格是温柔还是高冷、核心价值观是什么。这部分是刻在骨子里的，通常不会改变。
2.  **TOOLS（工具记忆）**
    它记得自己会哪些技能。比如它知道自己会发邮件、会写代码，这就像是它随身带的“工具包”。
3.  **USER（长期记忆）**
    它记得关于**你**的一切。你喜欢的颜色、你的工作习惯、你家猫的名字。这些信息会存在一个叫 `MEMORY.md` 的文件里，永远不丢。
4.  **Session（短期记忆）**
    这就是当前的聊天上下文。当你聊得太久，它会把之前重要的信息总结一下存入长期记忆，然后腾出空间来继续听你说话。

### “自动日记”功能
OpenClaw 每天都会给自己写日记（Daily Logs）。它会记录今天帮你处理了哪些任务，遇到了什么问题。当你明天再找它时，它会先翻翻昨天的“日记”，确保对话的连续性。

### 小贴士
你可以直接打开 OpenClaw 文件夹里的 `MEMORY.md` 文件。如果你觉得它记错了什么，直接用记事本修改这个文件，它就“改过自新”了。
