# 07 Agent 工作区：AI 的“独立办公室”

在 OpenClaw 里，每一个 Agent 都有一个属于自己的文件夹，我们管它叫 **Workspace**（工作区）。

### 文件夹里都有什么？
当你打开工作区目录，你会看到几个非常简单的文本文件：
*   `AGENTS.md`：Agent 的行为守则。
*   `SOUL.md`：它的基本人格。
*   `USER.md`：你的偏好设置。
*   `MEMORY.md`：它的长期备忘录。
*   `skills/`：它特有的、别人不会的“绝活”。

### 为什么采用这种设计？
*   **一切皆文本**：所有的配置都是 Markdown 或 JSON，你不需要专业的数据库知识，只要会打字就能配置它。
*   **方便迁移**：想换个服务器？直接打包这个文件夹带走，它在新的地方立刻就能恢复记忆，像从来没离开过一样。
*   **独立性**：你可以给老板养一个“商务虾”，给自己养一个“游戏虾”，它们住在不同的文件夹里，记忆和性格完全隔离。

### 新手建议
刚开始养虾时，不要乱动工作区里的文件。等你有了一定经验，你会发现通过修改这些 Markdown 文件来“调教”AI 是一种非常有成就感的体验。
