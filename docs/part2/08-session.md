# 08 Session 与用户识别：谁才是真正的老板？

OpenClaw 既然接入了社交软件，它是如何分清“主人”和“外人”的呢？

### 1. 配对码（Pairing Code）
当你第一次在飞书或 Telegram 上给你的 OpenClaw 发消息时，它不会理你，而是会给你一个 **6 位数的验证码**。
你需要在受信任的终端（比如你安装它的电脑）输入这个验证码，它才会正式认你做主。这防止了陌生人偷用你的 AI 和 API 额度。

### 2. 白名单（Allow List）
如果你想让你的家人或好朋友也能用，你可以把他们的 ID 提前写进“白名单”。这样他们发消息时，AI 就会直接响应，不需要验证码。

### 3. 会话隔离（Session Isolation）
*   **私聊模式**：它是你的贴身秘书，记得你所有的秘密和偏好。
*   **群聊模式**：它会自动开启“沙箱模式”。它在群里说话时，不会泄露你在私聊里告诉它的秘密，也不会把群里的闲聊存入你的核心长期记忆。

### 总结
这种设计既保证了使用的便捷性，又最大限度地保护了你的隐私。即使你在很多群里使用了 OpenClaw，你的核心数据依然是安全的。
