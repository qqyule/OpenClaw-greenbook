# 09 设计哲学：简单即是力量

OpenClaw 为什么这么火？因为它遵循了一套非常经典的“极简主义”哲学。

### 1. Unix 哲学：小而美
OpenClaw 不想做一个什么都能做的“巨无霸”，它只想做一个“总线”。它把复杂的功能拆解成一个个小工具。

### 2. 核心四大工具
虽然它能干很多事，但它底层最核心的工具只有 4 个：
*   **Read**：读文件
*   **Write**：写文件
*   **Edit**：改文件
*   **Bash**：运行命令（这是灵魂！）

只要学会了这四个动作，AI 理论上就能操作电脑上的任何软件。

### 3. 一切皆文本
不管是配置、记忆还是技能，OpenClaw 坚持使用纯文本（Markdown/JSON）。这意味着人类可以读懂它，AI 也可以轻松处理它。这种“透明感”是很多闭源 AI 软件不具备的。

### 4. 自我进化
OpenClaw 最厉害的地方在于：如果它发现自己不会干某件事，它可以尝试**自己写一个 Skill**（技能）来学会它。这种“自我扩展”的能力，让它随着使用时间越久，变得越聪明。
