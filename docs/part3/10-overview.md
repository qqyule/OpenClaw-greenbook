# 10 部署方式总览：选最适合你的那个

OpenClaw 可以在很多地方运行。你可以把它装在自己的电脑上，也可以装在云服务器上。

### 三种主流部署方案对比

| 方案 | 优点 | 缺点 | 适合人群 |
| :--- | :--- | :--- | :--- |
| **本地安装** | 免费、速度快、绝对隐私 | 关机就断网、需要环境配置 | 开发者、极客 |
| **云服务器一键部署** | 24小时在线、稳定性高 | 需要一点小钱（约10-20元/月） | **小白首选** |
| **Docker 部署** | 干净、好管理、易迁移 | 需要懂一点 Docker 知识 | 进阶用户 |

### 小白该选哪一个？
如果你刚开始尝试，**强烈建议选择国内云厂商（如阿里云、火山引擎）的一键部署方案**。它们通常已经把环境都配好了，你只需要点点鼠标就能跑起来。

### 关于成本的提醒
*   **服务器费**：目前国内云厂商首月通常只要几毛钱，长期也就几块钱一个月。
*   **API 费**：这是给 AI “大脑”交的学费。用得越多，费用越高。
*   **免费方案**：如果你完全不想花钱，后面我们会教你如何使用本地模型实现“零成本养虾”。
