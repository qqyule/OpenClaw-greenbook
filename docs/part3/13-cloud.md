# 13 国内云一键部署：小白的“捷径”

这是目前国内最火、最简单的养虾方式。大厂们（阿里、腾讯、百度等）都推出了 OpenClaw 专门的镜像。

### 1. 阿里云方案（推荐）
*   **价格**：首月通常有 9.9 元的活动。
*   **操作**：在轻量应用服务器里选择“OpenClaw”应用镜像，买完就能用。
*   **内置**：默认配好了通义千问模型，点开就能聊。

### 2. 火山引擎（字节跳动）方案
*   **特色**：深度集成飞书，飞书用户首选。
*   **套餐**：有一个“服务器+模型”的组合套餐，一个月不到 20 元，非常划算。

### 3. 百度云 & 腾讯云
*   **百度云**：甚至有 0.01 元首月的体验活动。
*   **腾讯云**：支持企微、QQ 原生接入，对社交场景支持极好。

### 4. 总结：该怎么选？
*   想省事、用飞书：选 **火山引擎**。
*   追求稳定、用钉钉：选 **阿里云**。
*   想接入 QQ、企业微信：选 **腾讯云**。
