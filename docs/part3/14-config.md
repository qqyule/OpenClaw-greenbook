# 14 首次配置：赋予它大脑与感官

不管你是在哪部署的，第一次启动后，你需要做几件关键的事。

### 1. 设置“大脑”（API Key）
AI 也是要吃饭的，API Key 就是它的“口粮”。
*   你需要去对应的平台（如阿里云百炼、Anthropic 官网、DeepSeek）申请一个 Key。
*   在配置页面填入这个 Key，AI 就能思考了。

### 2. 设置“身份”（SOUL.md）
它是谁？它是高冷的程序员，还是温柔的管家？
*   编辑工作区里的 `SOUL.md`。
*   写下你对它的期望，比如：“你是一个精通 Python 的全能助手，说话简练。”

### 3. 设置“感官”（消息频道）
你想在哪跟它说话？
*   **Telegram/Discord**：最快，5 分钟搞定。
*   **飞书/钉钉**：适合办公场景。
*   **QQ**：最接地气。

### 4. 诊断工具
如果你发现 AI 不理你，或者报错了，运行这条命令：
```bash
openclaw doctor
```
它会像医生一样帮你检查网络、模型、权限是否正常。
