# 15 渠道概览：在哪里跟 AI 说话？

OpenClaw 最大的魅力在于：它没有自己的 App，因为它能融入你手机里现有的所有聊天软件。

### 20+ 渠道全覆盖
目前 OpenClaw 支持超过 20 个国内外平台，主要分为以下几类：

1.  **极简入门型**：Telegram、QQ（扫码即用）。
2.  **办公神器型**：飞书、钉钉、Slack。
3.  **极客社区型**：Discord、Matrix、Nostr。
4.  **日常通讯型**：WhatsApp、微信（需中转）、iMessage。

### 接入难易度排行
| 平台 | 耗时 | 难度 | 备注 |
| :--- | :--- | :--- | :--- |
| **Telegram** | 5 分钟 | ⭐ | 本地可用，最推荐入门 |
| **QQ** | 5 分钟 | ⭐ | 扫码即用，国产首选 |
| **飞书/钉钉** | 15 分钟 | ⭐⭐ | 需要申请开发者权限 |
| **微信** | 1 小时+ | ⭐⭐⭐⭐ | 规则复杂，有封号风险 |

### 统一的接入流程
不管是哪个平台，流程通常都是三步走：
1.  **拿凭证**：在对应的平台创建一个“机器人”，拿到 Token 或 Key。
2.  **填配置**：把凭证写进 OpenClaw 的配置文件。
3.  **认老板**：在聊天软件里给它发消息，确认它是属于你的。
