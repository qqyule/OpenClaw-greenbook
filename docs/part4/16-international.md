# 16 国际平台接入：Telegram & Discord

如果你有科学上网环境，这两个平台是体验 OpenClaw 最顺滑的选择。

### 1. Telegram（最推荐）
Telegram 的配置是所有平台里最简单的。
*   **第一步**：搜索 `@BotFather`，给它发 `/newbot`。
*   **第二步**：按提示给机器人起个名字，拿到 **Bot Token**。
*   **第三步**：把 Token 填进 OpenClaw。
*   **优势**：不需要公网 IP，本地电脑就能跑。

### 2. Discord
适合想打造一个小社区或者多人协作的用户。
*   **关键点**：需要在 Discord 开发者后台开启 `Message Content Intent`（消息内容读取权限）。
*   **玩法**：你可以把不同的 Agent 拉进不同的频道，让它们帮你管群。

### 3. 其他平台
*   **WhatsApp**：直接扫码登录，非常方便，但对网络环境要求较高。
*   **Slack**：功能最强，适合把 AI 变成你的公司助理。
