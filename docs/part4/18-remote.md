# 18 远程访问：在外面怎么管理家里的 AI？

如果你的 OpenClaw 装在家里的电脑上，你出门在外想改个配置，该怎么办？

### 1. Tailscale：官方推荐
Tailscale 就像是一根无形的“虚拟网线”，把你所有的设备（电脑、手机、云服务器）连在一起。
*   **怎么用？** 在电脑和手机上都装上 Tailscale，你就能通过内网 IP 访问家里的 AI 了。
*   **安全**：全加密传输，不需要在路由器上开端口。

### 2. SSH 转发（开发者常用）
如果你懂一点 Linux 命令，可以用 `ssh -L` 把服务器的端口转发到本地，像操作本地软件一样操作远程 AI。

### 3. Web UI 控制台
OpenClaw 自带一个非常漂亮的 Web 界面（默认端口 3000）。通过浏览器，你可以直观地看到：
*   现在是哪个模型在干活？
*   今天用了多少 Token？
*   有哪些 Skills 正在运行？

### 注意
千万不要在没有任何防护的情况下把 18789 或 3000 端口暴露到公网，否则别人可能会偷走你的 API Key！
