# 19 Skills 工作原理：给 AI 装上“插件”

如果说 OpenClaw 是一个“数字员工”，那么 **Skills** 就是它掌握的各种“专业技能”。

### 什么是 Skill？
你可以把 Skill 理解为手机里的 **App**。
*   刚装好 OpenClaw 时，它只是个“大脑”，能跟你聊天。
*   装了 `Gmail` Skill，它就能帮你发邮件。
*   装了 `Browser` Skill，它就能帮你上网搜资料。

### 技能的三个来源
OpenClaw 会从三个地方找技能，优先级如下：
1.  **项目特有技能**：只针对这一个任务生效。
2.  **你安装的技能**：通过 `ClawHub` 下载的。
3.  **内置技能**：OpenClaw 自带的 55 个基础技能，开箱即用。

### 它是怎么工作的？
当你发消息说“帮我查一下 GitHub 上的那个 Issue”时：
1.  OpenClaw 会扫描它所有的技能说明。
2.  发现有个叫 `GitHub` 的技能刚好能干这活。
3.  它会告诉 AI：“嘿，你可以用这个工具。”
4.  AI 就会自动调用代码，把结果拿回来。
