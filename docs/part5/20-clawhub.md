# 20 ClawHub 技能市场：AI 的应用商店

`ClawHub` (clawhub.ai) 是 OpenClaw 官方的技能注册表，就像苹果的 App Store 或者安卓的 Google Play。

### 海量技能，随挑随选
目前 ClawHub 上已经有超过 **13,000** 个技能！涵盖了：
*   **办公辅助**：自动写周报、整理会议纪要。
*   **开发工具**：代码审查、自动提 PR。
*   **生活娱乐**：定外卖、放音乐、查股票。

### 常用命令
*   **搜索技能**：`openclaw skills search "搜索词"`
*   **安装技能**：`openclaw skills install 技能名`
*   **列出已装技能**：`openclaw skills list`

### 避坑指南（小白必看）
虽然技能多，但质量参差不齐。
*   **只装大品牌**：优先选官方或者 Star 数量多的技能。
*   **不要贪多**：装太多技能会让 AI 变得“困惑”，而且会消耗更多的 API 费用。
*   **注意安全**：有些坏人会上传带病毒的技能，下一章我们会专门讲安全。
