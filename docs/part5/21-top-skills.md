# 21 热门 Skills 推荐：这些一定要装！

为了让你少走弯路，我们从 1 万多个技能里精选了小白必装的“全家桶”。

### 1. Web Search（联网搜索）
**用途**：让 AI 能上网。没有它，AI 的知识只停留在过去；有了它，它能查今天的新闻。

### 2. Summarize（万能摘要）
**用途**：长文章、B站视频、PDF 文件太长不想看？直接扔给它，10 秒钟给你出总结。

### 3. Agent Browser（浏览器助手）
**用途**：不仅仅是搜索，它能像真人一样登录后台、填表、点按钮、截图。

### 4. GitHub
**用途**：如果你是开发者，这个技能能帮你管理 Issue、写 PR 说明，简直是效率神器。

### 5. Gmail / Google Calendar
**用途**：管理你的日程和邮件。它是“数字员工”变成“贴身秘书”的关键。

### 6. Image Gen（AI 生图）
**用途**：集成 DALL-E 或 Midjourney，在聊天框里说一句话就能帮你画图。
