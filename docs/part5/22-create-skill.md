# 22 自建 Skill 指南：自己动手，丰衣足食

如果你发现市场上没有你想要的技能，别担心，自己写一个其实非常简单。

### 什么是技能的最小单位？
一个技能最核心的就是一个叫 `SKILL.md` 的 Markdown 文件。

### 写一个“日报助手”技能
只需要创建一个文件夹，里面写一个 `SKILL.md`：
```markdown
# 日报助手
## 描述
每天帮我总结工作，写成漂亮的文章。
## 触发条件
当我提到“日报”或者“总结”时。
## 指令
1. 问我今天干了啥。
2. 按照“项目-进度-问题”的格式整理。
3. 保存到我的桌面。
```

### 为什么这很有用？
你不需要写复杂的代码，只需要用中文写清楚你的“要求”，OpenClaw 的 AI 就能理解并执行。

### 团队分享
你可以把你的技能分享到团队里，这样大家都能拥有一个同样的“超级助手”。
