# 24 模型提供商总览：给 AI 挑个好“大脑”

OpenClaw 本身是一个引擎，它需要接入 AI 模型（也就是它的“大脑”）才能工作。

### 主流“大脑”对比表

| 供应商 | 代表模型 | 优点 | 缺点 | 建议场景 |
| :--- | :--- | :--- | :--- | :--- |
| **Anthropic** | Claude 4.6 | 逻辑最强、干活最稳 | 贵、注册难 | 复杂编程、正式任务 |
| **OpenAI** | GPT-5.4 | 通用能力强 | 贵 | 日常百科、闲聊 |
| **DeepSeek** | V3.2 | **极致性价比**、中文好 | 高峰期可能卡顿 | **小白首选、主力干活** |
| **阿里/字节** | 通义/豆包 | 速度快、国内直连 | 偶尔会胡说八道 | 国内业务、批量处理 |
| **Ollama** | 本地模型 | **完全免费**、保护隐私 | 费电脑内存、智商上限低 | 隐私敏感、简单任务 |

### 核心策略：Fallback（备选方案）
OpenClaw 有个超强的技能：你可以设置一个“主力脑”和一个“备选脑”。
如果主力模型（比如 Claude）今天心情不好或者欠费了，OpenClaw 会自动切换到备选（比如 DeepSeek），活儿照样能干完。
