# 25 国际模型配置：追求极致的智力

如果你追求最好的体验，不在乎那点 API 费，国际大厂的模型是你的不二之选。

### 1. Anthropic Claude（OpenClaw 官荐）
OpenClaw 默认就是为 Claude 优化的。
*   **推荐型号**：`Claude 4.6 Sonnet`。
*   **为什么选它？** 它在理解复杂指令和调用工具方面，是目前公认的全球第一。
*   **怎么配？** 去 [console.anthropic.com](https://console.anthropic.com) 拿 API Key，填进配置文件即可。

### 2. OpenAI GPT
老牌强队，各方面表现都很均衡。
*   **注意**：GPT-5.4 后的价格策略比较复杂，长对话可能会变贵。

### 3. Google Gemini
*   **特色**：可以一次性读完好几本书的内容（超长上下文）。
*   **福利**：Google 提供了一定的免费额度，适合小白薅羊毛。
