# 26 国产模型配置：省钱又好用

对于国内用户来说，国产模型简直是“养虾”神器。

### 1. DeepSeek（性价比之王）
这是目前社区里最火的模型，没有之一。
*   **省钱秘籍**：它的价格只有国际模型的 **1/20**！
*   **能力**：代码能力和逻辑思维已经非常接近国际顶尖水平。
*   **配置**：baseUrl 填 `https://api.deepseek.com/v1` 即可。

### 2. 智谱 GLM 与 通义千问
*   **GLM**：代码能力非常强，有很多免费的“Flash”版本可以薅。
*   **通义千问**：阿里出品，如果你是阿里云用户，接入起来非常顺手。

### 3. 混合搭配建议
**小白最推荐的配置**：
*   **主力**：DeepSeek（干杂活，省钱）。
*   **备选**：Claude（干硬活，保质）。
这样你每个月可能只需要花几块钱，就能拥有一个超级聪明的 AI 助手。
