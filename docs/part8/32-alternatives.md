# 32 平替产品：如果 OpenClaw 太重了？

OpenClaw 虽好，但它确实有点占内存（运行时约 1GB）。如果你想在配置较低的机器上跑，可以看看这些“平替”。

### 1. nanoclaw
*   **特点**：只有 4000 行代码，非常轻量。
*   **适合**：想学习 Agent 架构原理的小白。

### 2. zeroclaw
*   **特点**：用 Rust 语言编写，速度快得惊人，几乎不占内存。

### 3. 托管方案
如果你连服务器都不想买，可以选择 `扣子(Coze)` 或者 `MiniMax` 的托管版，一键启用，不用操心维护。
